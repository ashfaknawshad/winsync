Which file do I want?

WinSync-Setup.exe

Recommended. Checks for the .NET 8 Desktop Runtime and installs it automatically — silently, and only if it's actually missing — then installs WinSync. Start Menu/desktop shortcuts, clean uninstall from Settings → Apps, no admin rights needed. The one to use if you don't want to think about any of this.

WinSync-Setup.msi

The same installer without the runtime check. Tiny (~700KB) because it relies on the .NET runtime already being on your machine — if it's not, you'll need to grab it yourself. Good if you already know you have it, or for scripted/silent installs.

WinSync.exe

Portable. One self-contained file (~70MB) with the .NET runtime bundled in. Nothing to install, nothing to uninstall — just delete the file when you're done with it.

Seeing "Windows protected your PC"?

That's Microsoft Defender SmartScreen, and it's expected — WinSync isn't digitally signed yet (working on that for free via SignPath). It's not a virus warning, just an "unrecognized publisher" notice. Here's how to run it anyway:

1

Click "More info"

The small link under the warning text — easy to miss.

2

Click "Run anyway"

The dialog expands to show the app name and this button appears.
